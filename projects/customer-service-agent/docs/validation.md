# 验证与运行边界

## 原版代码范围

本目录业务源码来自当前 `agent_v2/src/`，保留原包名和实现，不再使用泛化后的核心节选。导出时逐文件对比 SHA-256。

同时包含原版数据库迁移、启动与维护脚本、配置模板、容器文件、公开业务知识和测试。内部 `brands.md`、运行配置、客户数据库、付款凭证、商品图片及原始运维档案未发布。

一处历史测试中的私人姓名与电话改成示例值，业务源码没有相应改写。测试中的其他示例联系方式属于测试夹具，不是可联系的客户资料。

## 本地复现

Python 3.12，安装项目依赖后执行：

```bash
python -m unittest discover -s tests -v
```

在仓库根目录可以执行 `python scripts/run_checks.py`，完成公开文件基础检查与客服项目测试。客服项目未启用 GitHub Actions 自动测试，不能把本地结果说成云端 CI 已通过。

## 验证内容

包括业务状态机、结构化对话决策、动作校验、回调验签与解密、消息同步、幂等与重试、员工签名与 CSRF、OCR 规则、库存、官网申请，以及地址回复和人工交还 AI 回归。

这些测试使用隔离数据或模拟传输层，不发送真实微信消息，不证明支付实际到账，也不替代真实平台端到端验收。

2026-11-05，本次公开的原版业务源码与公开测试运行 162 项全部通过。没有引入新的真实客户咨询、预约或付款测试，后续修改以对应运行输出为准。

## 运行注意

- `scripts/smoke_dialogue.py` 会调用实际配置的模型接口，可能产生费用；它不是离线演示。
- `scripts/run_wecom_service.py` 启动真实客服服务，必须使用自己的平台授权、员工配置和私有业务材料。
- 数据恢复、任务重排与部署脚本可能改库、触发消息或重启服务，先审查并备份，不能直接对生产执行。
- 当前仓库不含独立官网静态站点，但保留官网预约申请的后端接口及员工管理功能。

## 未实现或未验证的能力

没有上线 Embedding、向量数据库和图片向量检索；OCR 不是支付平台到账核验。没有高并发压测、严格 exactly-once、可公开复现的准确率或转化率结论。
