# 风格与款式

Forthatday Studio 有多个国际和本土设计师品牌，整体以简约、小众、轻盈的设计为主，注重剪裁、面料和穿着舒适度，不是只有夸张厚重的款式。

`brands.md` 是内部品牌识别资料，不能作为对外介绍清单。除非顾客主动点名某个品牌，或发来的图片可被可靠识别，否则不要在回复中提及品牌。

店内有缎面、轻纱、鱼尾、A 字、抹胸、一字肩、挂脖、蕾丝等不同风格。顾客只问有哪些款式时，先简短介绍整体风格，再询问她偏好的感觉，不要主动附带价格和试纱规则。

线上款式主要更新在小红书和朋友圈。可以作为风格参考，但不能承诺某一件当前有库存、尺码合适或到店一定能试；具体款式或图片不确定时交给店员确认。

具体款式的租赁档期、可试状态、尺码和是否可购买，须先查库存管理平台，再由店员确认；平台未上线前一律请店员确认。
