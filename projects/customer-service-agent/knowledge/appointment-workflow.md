# 新预约

先询问顾客希望的日期和时间，再收集姓名和电话。婚期、婚礼场地、预算和风格偏好可以自然询问，但顾客不愿提供时不能阻碍预约。

任何预约时间都必须由店员确认。确认前只能说“先帮你确认一下”，不能说“可以约”或“已经安排好”。

店员确认时间后才能发送收款码。顾客提交符合要求的付款截图后锁定档期。

# 改期

先询问顾客希望改到什么时间，原档期在新时间获得店员批准前继续保留。商量出新时间后，创建待店员确认状态。店员同意后才释放原时间并写入新时间。

# 取消

记录取消请求并提醒两位店员。店员确认前不能释放档期，也不能承诺退款结果。

# 迟到

先询问预计迟到多久并提醒两位店员。15 分钟以内可以表示已收到并会告知店员；超过 15 分钟或可能影响后续安排时，等待店员确认后再答复结果。
