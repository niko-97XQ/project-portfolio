## 复现

基础验证只需 Python 3.12+：

```bash
python -m unittest discover -s tests -v
python demo.py
```

浏览器验证需 Node.js 和 Playwright：

```bash
npm install
npx playwright install chromium
npm run verify:ui
```

也可以通过 `BROWSER_CHANNEL` 选择本机已安装的兼容浏览器；通过 `PYTHON` 指定 Python 可执行程序。脚本仅创建自己的临时进程和演示数据，不连接业务生产服务。

## 覆盖范围

- 请求来源、同意声明、蜜罐、姓名、日期、时间、联系方式、消息长度和 UUID。
- 相同内容重试、变更内容冲突、重建存储后的重试，以及六个并发提交只写入一次。
- 客户端及号码频率限制、HMAC 摘要、处理状态白名单、过期行版本与审计写入。
- 真实本机 HTTP 传输、201/200 语义、错误来源、内容类型、请求体大小、重复字段，以及不公开申请列表和目录。
- 桌面及手机布局、滚动横移、键盘浏览、减少动态效果、Contact 显隐、真实合成表单提交，以及模拟摄像头的生命周期。

## 解释限制

公开测试数量以当前执行输出为准，不复用完整私有项目的历史测试数量。浏览器截图为本机产物，不上传真实客户影像。没有添加自定义 GitHub Actions 测试工作流，也不将本地执行或 Pages 发布构建称为云端测试 CI。

这些验证不能证明公网服务安全审计、生产并发能力、真实顾客到店转化率、预约已确认、支付已到账或 AI 试纱效果。演示中的持久化是真实 SQLite，但数据库生命周期被刻意限制在本机临时目录。
