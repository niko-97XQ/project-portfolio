# 婚纱工作室官网（V13 原版）

面向婚纱工作室的款式展示与预约入口，保留原 V13 的配色、照片展示和滚动交互。

## 原版网站

**[打开 V13 原版官网](https://api.forthatday-studio.com/bridal/)**

这是原来的业务网站，不是重新设计的占位图演示。请以浏览为主，不要为了测试而提交无意预约的申请。此前另做的脱敏展示页面已撤下，不再作为本项目的演示入口。

## 项目内容

- 浮动胶囊导航和首屏文字入场。
- 款式分类展示、纵向滚动驱动照片横移，以及画面放大。
- 预约表单默认关闭，只由 Contact 或 Appointment 的点击打开；关闭后保留未提交内容。
- 预约申请接入业务后端，成功只表示收到意向，不自动确认档期或收款。
- 实时 AI 换装仍处于探索阶段，未计入已完成功能。

## 工程取舍

1. 通过滚动进度驱动横向位移，避免再放一条横向滚动条；尺寸变化时重新测量。
2. 使用 `requestAnimationFrame` 合并滚动更新，在减少动态效果时保留可直接浏览的布局。
3. 将表单与展示分开，URL 中的 Contact 锚点本身不会自动弹出表单。
4. 网络超时不等于服务器未收到申请；内容未变时沿用提交键，后端仍需持久化去重。

## 公开范围与实现边界

原站照片、品牌素材和视觉保持在原站，不复制到公开仓库。仓库不提供客户记录、员工登录、密钥、服务器连接信息或运维配置。公开官网链接只指向前台，不授予后台访问权限。

项目在需求沟通、版本取舍、实现与验收中迭代，代码有 AI 辅助；不将其描述为完全独立、纯手工实现。本文不宣称业务转化提升、性能压测结果或全部婚纱都能被 AI 准确还原。
